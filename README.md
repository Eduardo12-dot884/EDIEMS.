# Quiz de estudio EDIEMS 2026–2027

## Ejecutar localmente
1. Descomprime el proyecto.
2. Abre `index.html` en un navegador moderno. No requiere servidor ni conexión a Internet.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube `index.html`, `style.css` y `script.js` a la raíz del repositorio.
3. En Settings → Pages, elige la rama principal y la carpeta `/ (root)`.
4. Guarda y abre la URL que GitHub Pages indique.

## Alcance de esta entrega
La guía adjunta tiene 357 páginas PDF. El rango solicitado corresponde a las páginas PDF 6–356. Esta es una primera versión funcional: incluye un catálogo inicial de secciones y preguntas verificadas contra el contenido visible del documento, pero **no cubre exhaustivamente todos los temas/subtemas ni todas las páginas 6–356**. Las secciones con cobertura parcial están señaladas dentro de la aplicación; no se inventaron preguntas para completarlas. Para cumplir el criterio de aceptación de cobertura total hace falta continuar extrayendo y verificando los contenidos restantes por bloques.

El número de página mostrado en cada pregunta es la página impresa que aparece en la guía cuando pudo determinarse. `localStorage` es local al navegador/dispositivo. El temporizador es opcional y no afecta la calificación.
